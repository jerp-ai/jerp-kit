# Custom GPT

1. Paste `gpt/INSTRUCTIONS.md` into the GPT's Instructions (about 3,900 characters; the limit is 8,000).
2. Actions -> import `https://getjerp.com/api/v1/openapi.json`.
3. Authentication: API key, Bearer, with a key from `https://getjerp.com/lab`. Without a key the open door `https://getjerp.com/open/api/v1/` answers with lower limits.
